# CS2 Memory Aimbot

Открытый memory-чит для CS2 на Python. Без стиллеров, без скрытого кода — весь исходник открыт.

## ⚠️ Дисклеймер

- Использование читов **нарушает** соглашение Valve
- **VAC может забанить** аккаунт
- Используй **только на свой страх и риск**
- Проект создан в **образовательных целях**

## 🎯 Фичи

### Aim
- Аим через микро-углы (человечный)
- Sensitivity из памяти
- Recoil control (компенсация отдачи)
- Spotted проверка (точная видимость)
- Target Lock (не прыгает между врагами)
- Авто-определение оружия
- Настройка шансов: HEAD / BODY / LEGS

### Trigger
- Burst логика (Press / Release)
- Пресеты: PISTOL / AUTO / AWP
- Клавиша активации настраиваемая
- Авто-определение оружия

### ESP
- Скелеты врагов
- Трассеры от тебя
- Цвета настраиваемые

### Доп. фичи
- Bhop (авто-прыжок)
- Anti-flash
- No-recoil

### UX
- Меню с анимациями, иконками, тултипами
- Трей-иконка
- Окно "Ожидание CS2"
- Авто-закрытие при выходе CS2
- Trusted Mode detection
- Предупреждения

## 📋 Требования

- **Windows 10 / 11** (x64)
- **Python 3.11+**
- **CS2** (Steam версия)
- **NVIDIA GPU** (не обязательно)

## 🚀 Установка

### Вариант 1: `.exe` (проще)

1. Скачай `CS2_Memory_Aimbot.exe` из [Releases](../../releases)
2. Запусти `.exe`
3. Запусти CS2
4. Чит подхватится сам

### Вариант 2: Python (для разработчиков)

```bash
# Установить зависимости
py -3.11 -m pip install -r requirements.txt

# Запустить
